The difference among var,const and let that is
*var is a old method of javascript that uses for function scope,value redeclare and reassign.
and it has problem that is function scope and it access the out of function scope.

*let is the feature of ES6 and it block scope function ,reassign

2️⃣ What is the spread operator (...)?
*Spread operator(...)is used expand the elements of array or object.we used spread operator for array copy,array merge ,object merge and function arguments.
Ex.
//merge the element
let num1 = [1,2,3,4];
let num2 = [5,6,7];
let result = [...num1,..num2]//output:1,2,3,4,5,6,7

3️⃣ What is the difference between map(), filter(), and forEach()?
* map() is the method of javascript that apply the function of all array element and return a new array.

*filter() is the method of javascript that filter the element according to conditions and return a new array..

*forEach is a array method of javascript that execute the function by the loop on each element but do not return a new array.
